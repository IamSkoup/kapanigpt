# KapaniGPT

Исходный код KapaniGPT — русскоязычного ИИ-чата с авторизацией Firebase, историей сообщений, настройками, несколькими профилями моделей, системой лимитов, внутренними токенами и пробным Kapani AI plus.

Текущая публичная версия приложения работает на [kapanigpt.netlify.app](https://kapanigpt.netlify.app/). Адрес [iamskoup.github.io/kapanigpt](https://iamskoup.github.io/kapanigpt/) перенаправляет на Netlify. Этот репозиторий содержит код приложения, но не копию пользовательских аккаунтов, базы данных или серверных секретов.

## Запуск для разработки

Нужны Node.js 22.13 или новее, npm и настроенная база PostgreSQL. Установи зависимости с `npm ci`, затем запусти `npm run dev`. Для сборки используется `npm run build`. Firebase-проект, Netlify Database, миграции и переменные окружения настраиваются отдельно.

Серверные маршруты находятся в `app/api/`. Они отвечают за ИИ, учёт лимитов, подписки, пробный период и безопасность операций. Веб-интерфейс находится в `app/` и `components/`.

**Важно о хостинге.** GitHub Pages не запускает Next.js API-маршруты и PostgreSQL, поэтому в `docs/index.html` размещено только перенаправление на Netlify, а не копия приложения. Сам ИИ-чат работает на Netlify с серверной базой данных.

Авторская расширенная база знаний заменена в `lib/master-prompt.md` нейтральным шаблоном. В публичную копию намеренно не вошли личные истории людей и внутренние данные живого проекта. Для собственной установки используй свой текст.

## Интернет-поиск

KapaniGPT автоматически решает, нужен ли для вопроса веб-поиск. Серверный `/api/chat` получает до пяти результатов и передаёт модели только заголовки и короткие выдержки. Серверные источники показываются отдельно в интерфейсе и сохраняются в истории. Для Brave Search можно добавить `BRAVE_SEARCH_API_KEY` в переменные окружения Netlify (никогда не в `NEXT_PUBLIC_*` и не в Git). Без ключа сервер пробует RSS Bing. Резервный поиск не гарантирован, поэтому при его недоступности модель должна честно сообщать, что актуальные источники не получены. Таймауты и объём поиска ограничены.
