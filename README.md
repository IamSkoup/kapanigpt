# KapaniGPT

Исходный код KapaniGPT — русскоязычного ИИ-чата с авторизацией Firebase, историей сообщений, настройками, несколькими профилями моделей, системой лимитов, внутренними токенами и пробным Kapani AI plus.

Текущая публичная версия приложения работает на [kapanigpt.kion-simbovich.chatgpt.site](https://kapanigpt.kion-simbovich.chatgpt.site). Этот репозиторий содержит код версии 16 от 9 ноября 2026 года, а не копию пользовательских аккаунтов, базы данных или серверных секретов.

## Запуск для разработки

Нужны Node.js 22.13 или новее, npm и локальная конфигурация платформы Sites/Cloudflare для D1. Установи зависимости с `npm ci`, затем запусти `npm run dev`. Для сборки используется `npm run build`. Firebase-проект, база D1, миграции и привязка к хостингу настраиваются отдельно.

Серверные маршруты находятся в `app/api/`. Они отвечают за ИИ, учёт лимитов, подписки, пробный период и безопасность операций. Веб-интерфейс находится в `app/` и `components/`.

**Важно о хостинге.** GitHub Pages не запускает Next.js API-маршруты, Worker и Cloudflare D1. Поэтому один лишь перенос этого репозитория на GitHub Pages не даст работающий ИИ-чат и не решит проблему доступа к домену `chatgpt.site` из некоторых сетей. Для переезда без Cloudflare нужен отдельный совместимый серверный хостинг и перенос базы, а затем переключение адреса.

Авторская расширенная база знаний заменена в `lib/master-prompt.md` нейтральным шаблоном. В публичную копию намеренно не вошли личные истории людей и внутренние данные живого проекта. Для собственной установки используй свой текст.
