# FedyaGPT

FedyaGPT — русскоязычный ИИ-чат с Firebase-входом, историей, настройками ответов, текстовыми файлами, изображениями для анализа и серверным учётом лимитов.

Рабочий адрес — [kapanigpt.netlify.app](https://kapanigpt.netlify.app/). [iamskoup.github.io/kapanigpt](https://iamskoup.github.io/kapanigpt/) перенаправляет на него. GitHub Pages не поддерживает Next.js API, PostgreSQL и Firebase-серверные функции, поэтому основное приложение разворачивается на Netlify.

## Запуск

Используются Node.js 22.13+, Next.js, PostgreSQL и Firebase Authentication. Команды `npm ci`, `npm run dev`, `npm test` и `npm run build`. Конфигурация Firebase, PostgreSQL и Netlify задаётся отдельно через переменные окружения, никаких ключей в Git.

## Общие знания о Капанях

В `lib/kapani-public-lore.ts` находится единый публичный художественный канон, составленный из авторского исходного материала. Это не интерфейсная настройка и не личная память посетителя. Функция `kapaniSystemKnowledge()` в `lib/knowledge.ts` передаёт модельному шлюзу соответствующие части канона как серверную системную инструкцию для **всех аккаунтов**, автоматически. Для обычных запросов используется короткая инструкция, чтобы не перегружать модель большим контекстом. При обращении к Капаням, персонажам, фильмам и соответствующему лору подключается подробная база.

Пользователи не обязаны загружать никаких файлов, указывать UID Firebase, менять настройки Netlify или восстанавливать базу PostgreSQL. Пункты импорта/статуса базы знаний намеренно удалены из публичной «Персонализации», а прежние API загрузки авторского промпта отключены. Ни один пробел в PostgreSQL больше не лишает ИИ знания основной вселенной.

Оригинальный 66-КБ мастер-файл содержит не только художественные сведения, но и частные биографии, исторические сведения о людях и устаревшие инструкции с вымышленными моделями, тарифами и лимитами. Он не публикуется целиком, чтобы не делать частные данные общедоступными и не вносить ложные инструкции о действующем продукте. Из него отобраны безопасные творческие факты, персонажи, сюжеты и правила повествования. Это расширенный публичный канон, а не полная дословная копия исходника.

## Персонализация и стиль общения

По умолчанию выбран стиль «Дерзкая, с матами». Допустимы сарказм, разговорная речь и ненормативная лексика к месту; это не отменяет полезные ответы и корректную работу с серьёзными вопросами. Пользователь может поменять тон в «Настройки → Персонализация». Персональные поля «Что ИИ стоит знать о тебе» и «Как лучше отвечать» относятся только к соответствующему аккаунту.

## Интернет, вложения и изображения

Поиск источников работает на сервере через Brave Search с `BRAVE_SEARCH_API_KEY`; без ключа приложение может пробовать резервный поиск. Ссылки на источники выводятся отдельно от текста ответа.

В работе serval 1 использует Liquid LFM3, leopard 1 — Baidu ERNIE Flash, lion 1 — Cohere North Mini Code. Это профили FedyaGPT поверх действующих сторонних моделей; каталог провайдера и доступность бесплатных основ могут измениться. Обычный чат использует автоматический выбор. Под ответом указана фактическая модель, возвращённая шлюзом, и время генерации. Модели анализируют сжатые JPEG/PNG/WebP через серверную передачу изображений в мультимодальный шлюз. PDF/DOCX пока не разбираются, но текстовые файлы можно прикреплять. PNG/JPEG-генерация не подключена; платный тариф может создать и показать SVG-файл. Внешние шлюзы имеют собственные ограничения доступности и времени ответа.

## Безопасность

Не сохраняйте секреты API, `DATABASE_URL` и оригинальные частные архивы в Git. Авторский канон в `lib/kapani-public-lore.ts` трактуется как творческое описание, не как достоверные биографии реальных людей. Вымышленные персонажи, кинороли и реальные люди не должны смешиваться. Если сведения о новом герое не установлены, модель должна спрашивать уточнение или явно обозначать новую выдуманную сцену.

## Платежи ЮKassa

Подписки 19/49/79/99 ₽ действуют один календарный месяц, без автоматического продления. Новые покупки используют только серверный API ЮKassa. Таблица `ai_yoo_checkouts` создаётся миграцией `20261117180000_yookassa.sql`; старый банк Капаней и покупка токенов отключены. Установите секретные переменные `YOOKASSA_SHOP_ID` и `YOOKASSA_SECRET_KEY`, а также `FEDYA_SITE_URL=https://kapanigpt.netlify.app` в окружении Netlify. Без них оплата отвечает 503 и деньги не списывает. На возвращении покупателя сервер сверяет статус, сумму, валюту и метаданные платежа прямым запросом к ЮKassa, а затем атомарно активирует подписку. Ключи не помещаются в браузер или Git.

Для подключения магазина самозанятого зарегистрируйтесь в [кабинете ЮKassa](https://yookassa.ru/my), укажите ИНН и реквизиты, получите shopId и секретный ключ. Понадобятся опубликованные сведения о продавце и правила продажи цифровой услуги, которые должны соответствовать фактическим данным владельца. До готовности кабинета платные тарифы показываются в интерфейсе, но оплачивать их нельзя.
